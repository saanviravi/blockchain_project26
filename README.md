# Blockchain-Based Emergency Healthcare Access Control

Smart contract implementation of ABAC + Break-Glass emergency protocol on Polygon.

## Stack
- Solidity 0.8.28
- Hardhat 3.2.0
- TypeScript / Mocha / Ethers.js

## Run tests
